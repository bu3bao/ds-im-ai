## Q1：用户名是什么？需要注册吗？
（用户可能问“用户名是什么”“用户名填什么”“账号是什么”等，都按本条回答）
需要注册一个账号，过程很快：

1. 点页面右上角「登录 / 注册」，再点「立即注册」
2. 填写用户名和邮箱，点「发送验证码」，到邮箱里取验证码填上，再设置一个密码
3. 注册成功后，您设置的用户名就是账号，以后登录填「用户名 + 密码」这两样即可

请注意：这个账号仅用于本网站，与 DeepSeek 的账号是两个独立体系、不互通，DeepSeek 的账号问题本站无法代为查询或处理。

【硬性要求】回答本条时，上面“请注意”一段必须完整带上、不得省略——很多用户会误拿 DeepSeek 的账号密码来登录，这段话就是防这个误会的。

如需更多次数，可在站内直接升级：月卡会员 ¥9.9（30 天不限次）、永久会员 ¥29.9，支付宝付款，完成后即时生效。

## Q3：点了「解析」没反应 / 提示要先登录？
解析功能需要先登录后使用。看到输入框下方提示"请先登录后再使用解析功能"，点右上角「登录 / 注册」登录后再试即可。

如果当天 3 次已用完，会自动弹出升级窗口，这代表当日次数已使用完毕，属正常提示。

## Q4：页面异常、功能没有响应怎么办？
请一步步试下面的方法，大部分情况都能解决：

1. 关掉网页，重新打开再试一次
2. 如果是在微信、QQ 等应用里点开的：这些应用内置的浏览器没有下载功能，导出功能也无法正常使用，请点右上角「…」，选择「在浏览器打开」
3. 手机里没有合适浏览器的，建议到各手机应用商店搜索下载「Chrome」或「Via」（Via 体积很小）；应用商店搜不到时，可 [点此访问 Via 官网](https://viayoo.com) 或 [点此访问 Chrome 官网](https://www.google.cn/chrome/) 下载。苹果手机使用系统自带的 Safari 即可
4. 还不行可尝试无痕模式：苹果在 Safari 点地址栏左侧图标 →「新私密标签页」，其他浏览器在菜单里找「无痕/隐私模式」，在无痕窗口中重新打开网站
5. 以上都尝试后仍有异常，请描述具体情况，会协助进一步排查

## Q5：收不到注册验证码怎么办？
可按以下顺序查看：

1. 打开邮箱的「垃圾邮件 / 订阅邮件」文件夹看看，验证码邮件通常会掉在那里
2. 确认使用的是 QQ、163、Gmail、Outlook 等常见邮箱，部分小众邮箱可能无法送达
3. 等待 60 秒后重新点「发送验证码」，再查一次垃圾邮件文件夹

## Q6：这个网站的密码忘了怎么办？
在登录页点「忘记密码」，填入注册邮箱，按提示即可自助重置。

如果当前已登录，也可在个人中心「修改密码」直接更换。

另请留意：这是本网站的登录密码，与 DeepSeek 的账号密码是两个独立体系，不互通。

## Q7：能导出哪些格式？选哪个？
解析完成后可导出 7 种格式：PDF、Word、图片、HTML、Markdown、TXT、JSON。

· 配合提示词使用 → TXT 或 JSON，JSON 保留的信息更完整
· 发给人看、打印 → PDF 或 Word
· 自己保存阅读 → TXT，大部分设备都能直接打开

## Q8：导出的文件去哪里了？找不到怎么办？
通常来说，下载的文件会保存在设备的"下载"位置：

· 安卓手机：一般在「文件管理」App 的「下载（Download）」文件夹，不同品牌手机的菜单位置略有差异
· 苹果手机：在系统自带的「文件」App →「下载项目」
· 也可以直接在浏览器菜单里点「下载内容 / 下载记录」查看

特别提醒：如果是在微信、QQ 等应用内打开本网页下载的，因这些应用的内置浏览器不提供下载管理，文件很可能无法保存，请改用系统浏览器打开 [https://ds.aikeyu.cn](https://ds.aikeyu.cn) 重新导出。

## Q9：续写提示词是什么？我在哪拿？
「续写」卡片是公开内容，不需要登录、不需要注册，在网站首页下方就能看到，点卡片上的「复制」按钮即可拿到完整提示词。

如果用户就在对话窗口里问，可以直接把下面全文发给用户，让其复制使用：

你现在需要帮助用户继续上一次对话。用户已经通过文件上传入口上传了上一轮对话的完整记录文件（TXT 或 JSON 文件）请你完整阅读并理解，把它作为上下文，接着在这个新窗口中继续对话。

核心原则：
1. 文件内容就是上一轮对话记录，对话可能很长，请确保你完整理解对话内容，包括用户的问题、你的回答、用户的补充信息和情绪状态。
2. 你要将它当作完整的上下文，仔细阅读并理解整个对话上下文、主题、风格和进展，不要遗漏任何细节。
3. 你需要在新窗口中延续上一轮的逻辑、风格、语气和主题；理解关系背景把握对话中建立的任何关系。
4. 不要生成摘要，也不要自行删减信息，确保上一轮的细节被完全保留。
5. 如果存在内容不清楚或存在矛盾，可以提出澄清问题，但不要自行假设重要信息。
6. 在生成回复时要自然延续，请以"延续上轮对话"方式进行，而不是当作新独立会话。
